🔗 Configurações por URL
Como usar:
1. Cole configurações no campo abaixo
2. Clique em "Gerar URL Compartilhável"
3. Compartilhe a URL ou cole no navegador
4. Se usar ?auto=1 na URL, carrega automaticamente
Formato: 10 valores separados por ; (ponto e vírgula)
Ordem: sensibilidade, velocidade_preenchimento, velocidade_barra, sensibilidade_ecg, suavidade_ecg, zoom_ecg, limiar_piscar, multiplicador_velocidade, repeticoes_troca, caminho_imagem
Extensões suportadas: GIF, PNG, JPG, JPEG, BMP, WEBP, MP4, AVI, MOV
Caminhos: URLs web (http/https/www) ou caminhos locais (/storage/emulated/0/...)
Modo de uso: Cada linha é uma configuração. O sistema carrega a primeira linha automaticamente. Quando completar as repetições, avança para a próxima linha.
Seleção: Use o checkbox "Selecionar" na playlist para restringir a navegação (botões e toque na tela) apenas aos exercícios marcados.
